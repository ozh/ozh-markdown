# Ozh' Markdown Plugin

> A split-pane **Markdown editor for WordPress**

## What

Markdown on the left, live preview on the right. No blocks, no WYSIWYG. Write like it's GitHub.

Posts are saved as plain HTML, so your content still renders if you deactivate the plugin. Code blocks get syntax highlighting, and you can drag and drop images straight into the editor.

## Why did I make this

Out of the dozens of existing Markdown plugins, all I found was:
* bloated (upload `.md` files, manage gists, ...)
* dead ("Removed for security reasons on [_5 years ago_]")
* partial or clumsy

This plugin just does what it says, no more, no less. [Example output](https://planetozh.com/blog/2026/10/a-per-repo-untracked-gitignore-local/).
