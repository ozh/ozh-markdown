# Ozh' Markdown Plugin

> A split-pane **Markdown editor for WordPress**

## What

Markdown on the left, live preview on the right. No blocks, no WYSIWYG. Write like it's GitHub.

Posts are saved as plain HTML, so your content still renders if you deactivate the plugin. Code blocks get syntax highlighting, and you can drag and drop images straight into the editor.
